👋 Welcome!

It's great to have you here. I'm sure you will love this course. ❤️

## What will you learn?

By taking the Cypress & Cucumber course, you will learn:

- How to install and configure Cypress and Cucumber
- How to write a simple feature file
- How to write a simple step definition
- How to write a feature with parameters
- How to write a step definition with parameters
- How to write a feature with a data table
- How to write a feature with an array
- How to write a step definition with an array
- How to use the Background keyword to share setup steps
- How to define and reuse common step definitions
- How to organize and run tests using tags
- How to generate an HTML report of the test execution
- How to run Cypress and Cucumber tests on CI
- When to consider a simplified solution without Cucumber
